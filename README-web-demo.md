# Sudoku Solver — Java + Web Demo

A Java-based 9x9 Sudoku solver using the Backtracking algorithm.

## Live Demo
After enabling GitHub Pages, the website will be available at:

`https://tasneemsakriwl5253.github.io/Sudoku-Solver-Java/`

## Files
- `SudokuSolver.java` — original Java implementation.
- `index.html` — web interface.
- `style.css` — responsive styling.
- `script.js` — browser version of the backtracking solver.

## Algorithm
The solver searches for an empty cell, tries numbers 1–9, checks whether each number is valid, and backtracks when a choice cannot lead to a solution.
